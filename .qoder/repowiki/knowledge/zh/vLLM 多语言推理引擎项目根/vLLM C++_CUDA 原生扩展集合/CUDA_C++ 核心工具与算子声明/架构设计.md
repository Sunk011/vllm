本模块由一组纯头文件组成，按职责划分为四层：
- 类型分发层（dispatch_utils.h）：基于 PyTorch 的 AT_DISPATCH 机制封装 VLLM_DISPATCH_* 宏族，支持浮点、半精度、FP8、整型、字节及向量维度等编译期/运行时分发，并针对 ROCm 的 e4m3fn/e4m3fnuz 双 FP8 格式做条件分支。
- 设备兼容层（cuda_compat.h、cuda_utils.h）：通过 USE_ROCM / __HIPCC__ / __CUDACC__ 宏在 HIP 与 CUDA 之间桥接 warp size、shfl 指令、LDG 读取、共享内存属性设置等底层 API；同时提供 HOST_DEVICE_INLINE 等跨编译器内联宏和 CUDA_CHECK 错误检查。
- 算子接口层（ops.h）：集中声明 rms_norm、rotary_embedding、silu_and_mul、gelu_*、静态/动态 int8 量化等算子函数签名，供 CPU 与 CUDA 后端共同实现，并通过 torch::Tensor 作为统一张量抽象。
- 工具与缓存层（torch_utils.h、cache.h）：torch_utils.h 提供统一的 TORCH_UTILS_CHECK 宏以兼容稳定版与不稳定版 libtorch；cache.h 定义 KV Cache 的核心操作（swap_blocks、reshape_and_cache、concat_and_cache_mla、gather/dequant、FP8 upconvert、indexer K quant 等），是注意力前向/反向中缓存读写的主入口。
依赖方向：ops.h 依赖 core/scalar_type.hpp；所有文件均依赖 torch/all.h 或 torch/library.h；cuda_compat.h 与 cuda_utils.h 被其他头文件包含以屏蔽硬件差异，不反向依赖上层算子。
