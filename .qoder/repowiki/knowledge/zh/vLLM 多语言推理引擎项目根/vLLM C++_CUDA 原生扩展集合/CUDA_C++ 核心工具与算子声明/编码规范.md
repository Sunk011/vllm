- 所有跨 CUDA/HIP 的差异通过 #ifdef USE_ROCM / #ifndef USE_ROCM 宏包裹，提供等价宏名（如 WARP_SIZE、VLLM_SHFL_*、VLLM_DevFuncAttribute_SET_MaxDynamicSharedMemorySize）屏蔽底层 API 差异。
- 类型分发统一使用 VLLM_DISPATCH_* 宏族包装 AT_DISPATCH_SWITCH，避免直接调用 ATen 内部宏，保持分发逻辑集中且可复用。
- 算子接口统一采用 torch::Tensor& 作为输入输出参数，可选参数使用 std::optional<torch::Tensor> 表示，函数签名风格保持一致。
- 设备端函数通过 HOST_DEVICE_INLINE / DEVICE_INLINE / HOST_INLINE 宏统一标注 __host__ __device__ __forceinline__，确保同一份代码可在 host 与 device 编译。
- 错误检查统一使用 CUDA_CHECK 宏包装 cudaError_t 返回值，并在失败时打印文件名、行号与错误字符串后退出进程。
