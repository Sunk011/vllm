- 所有算子原型集中在 ops.h 中声明，CPU 与 CUDA/ROCm 实现分别通过各自的 torch_bindings.cpp 注册到同一扩展名。
- CUDA 与 HIP 差异通过 cuda_compat.h 中的宏（WARP_SIZE、VLLM_SHFL_*、VLLM_LDG 等）在编译期统一抽象。
- 按 USE_ROCM 条件编译分离 ROCm 专属代码，非 ROCm 路径默认走 CUDA 实现。
- 量化与 MoE 相关 kernel 按 dtype（int4/int8/fp8/nvfp4/w8a8）与架构（sm90/sm100/sm120/c2x/c3x）分层组织在 quantization/ 与 moe/ 子目录下。
- Python 绑定统一使用 TORCH_LIBRARY_FRAGMENT 与 REGISTER_EXTENSION 宏进行 op 注册，meta 函数签名与实现保持同步。
