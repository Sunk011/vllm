- ROCm 与 CUDA 差异通过 `#ifdef USE_ROCM` / `#ifndef USE_ROCM` 预处理器分支在同一文件中并行维护，避免拆分文件。
- Python 扩展统一通过定义 `PyMethodDef` 数组 + `PyModuleDef` 结构体 + `PyMODINIT_FUNC PyInit_xxx` 导出模块的方式实现。
- 涉及 Python 对象交互的代码段使用 `PyGILState_Ensure()` / `PyGILState_Release()` 显式获取和释放 GIL，或在 `Py_BEGIN_ALLOW_THREADS` / `Py_END_ALLOW_THREADS` 宏内释放 GIL 后调用非 Python 代码。
- CUDA/ROCm 错误通过统一的 `CUDA_CHECK` 宏捕获，将错误码写入全局 `error_code` 并用 `snprintf` 填充 `error_msg` 供后续 `PyErr_SetString` 抛出。
- PyTorch op 注册采用 `TORCH_LIBRARY_FRAGMENT` + `.def(...).impl(...)` 模式，meta 函数签名与实现保持同步。
- 向 Python 传递多值结果时使用 `PyTuple_New` + `PyTuple_SetItem` 构造元组，整数统一用 `PyLong_FromUnsignedLongLong` 转换。
