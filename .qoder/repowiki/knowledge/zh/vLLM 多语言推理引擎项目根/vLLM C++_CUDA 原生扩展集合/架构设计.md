该目录是 vLLM 所有 C++/CUDA 原生扩展的统一根，按目标平台与功能划分为多个并列子模块：
- core/ 提供跨后端的类型分发、异常与注册接口，被所有子模块共享。
- cpu/ 包含 CPU 端注意力、GEMM、MoE、激活等实现及 micro_gemm/s gl-kernels 优化路径。
- cutlass_extensions/ 与 libtorch_stable/cutlass_extensions/ 分别提供 CUTLASS 自定义 epilogue 与稳定 ABI 封装。
- libtorch_stable/ 存放 CUDA ROCm 专用 kernel（attention、moe、quantization、activation_kernels 等），通过 stable ABI 与 Python 交互。
- rocm/ 提供 ROCm 专属 kernel 与 torch_bindings.cpp 片段。
- attention/、moe/、quantization/、quickreduce/ 为跨平台的通用头文件与轻量实现。
- 顶层 torch_bindings.cpp、ops.h、cuda_compat.h 作为统一边界：ops.h 声明所有算子原型，cuda_compat.h 用 USE_ROCM 宏屏蔽 CUDA/HIP 差异，各子模块的 torch_bindings.cpp 通过 TORCH_LIBRARY_FRAGMENT 或 REGISTER_EXTENSION 将实现注册到同一扩展名。
- 运行时由 cumem_allocator.cpp、custom_quickreduce.cu、fs_io.cpp、spinloop.cpp 等底层设施支撑内存、通信与 I/O。
