- 每个 MkDocs 页面顶部使用 YAML front matter 控制导航与搜索行为（如 `hide: [navigation, toc]`、`toc_depth`、`search.exclude`）。
- 构建钩子统一通过 `on_startup(command, dirty)` 函数暴露，并在内部通过 `logger = logging.getLogger("mkdocs")` 记录生成过程。
- 需要导入 vLLM 源码的钩子使用 `auto_mock` 模式：先尝试 import，失败时用 `PydanticMagicMock` 或 `MagicMock` 动态注册到 `sys.modules` 再重试。
- 生成的中间文档写入 `docs/generated/` 目录，文件名以 `<stem>.inc.md` 结尾，供 MkDocs 通过 `--8<--` 语法 include。
- 相对链接在示例生成时被转换为 GitHub 绝对 URL（`https://github.com/vllm-project/vllm/tree/main` 或 `blob/main`），保证跨仓库引用稳定。
