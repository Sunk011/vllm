文档以 Markdown 为主，通过 `.nav.yml` 定义 MkDocs 导航结构，按 User Guide / Developer Guide / Benchmarking / API Reference / CLI Reference / Community 等顶层章节组织。
- `mkdocs/hooks/` 提供 MkDocs 构建钩子：`generate_argparse.py` 通过反射 vLLM 的 argparse 类（EngineArgs、AsyncEngineArgs、各 CLI 命令）并自动 mock 缺失依赖，生成 `docs/generated/argparse/*.inc.md`；`generate_examples.py` 扫描 `examples/` 目录并按分类自动生成 `docs/examples/<category>/<file>.md`。
- `mkdocs/javascript/`、`mkdocs/stylesheets/extra.css`、`mkdocs/overrides/` 定制 MkDocs 主题行为（数学公式 MathJax、编辑反馈、Slack/Forum 集成、TOC 项渲染）。
- 静态资源集中在 `assets/`，按 contributing/deployment/design/features/models/training 等用途分目录存放图片与 SVG。
- 内容目录按用途划分：`getting_started/`、`usage/`、`serving/`、`deployment/`、`configuration/`、`design/`、`features/`、`models/`、`training/`、`benchmarking/`、`contributing/`、`community/`、`governance/`、`cli/`、`api/`。
- 依赖方向单向：钩子脚本读取源码与 examples 目录生成中间文档，再由 MkDocs 聚合为最终站点，不反向影响源码。
