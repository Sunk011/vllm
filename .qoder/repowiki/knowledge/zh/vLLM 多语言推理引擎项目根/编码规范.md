- 所有 Python 代码统一通过 ruff 进行 lint/format，pyproject.toml 中集中定义 ignore 规则与 per-file 忽略
- 原生扩展通过 CMake 的 define_extension_target 宏统一注册，按 VLLM_GPU_LANG 条件编译 CUDA/HIP/CPU 变体
- 依赖按后端（CPU/CUDA/ROCm/XPU/TPU）与用途（common/dev/lint/docs/test）拆分 requirements 文件，由 uv 生成 .txt 锁定
- 测试通过 pytest markers（slow_test、distributed、cpu_test 等）分类，CI 按标记并行执行
- 文档通过 MkDocs hooks 自动生成参数引用与示例页面，docs/guides 与 docs/design 分离用户指南与设计文档
