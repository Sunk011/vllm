该目录是 vLLM 的根包，采用按职责划分的扁平子包结构：
- `config/`：基于 Pydantic dataclass 的配置体系（VllmConfig 组合 Attention/Cache/Compilation/Device/Diffusion/KVTransfer/Lora/Mamba/Model/MultiModal/Observability/Offload/Parallel/Profiler/Reasoning/Scheduler/Speculative/StructuredOutputs/WeightTransfer 等子配置），由 `engine/arg_utils.py` 通过数据类反射生成 CLI 参数。
- `engine/`：暴露 LLMEngine / AsyncLLMEngine 以及 EngineArgs / AsyncEngineArgs，作为用户 API 与底层 v1 执行器的桥接层。
- `model_executor/`：模型定义（`models/` 下数百个具体模型实现）、Layer 实现（attention/linear/moe/quantization/rotary_embedding 等）、权重加载器（default/bitsandbytes/tensorizer/sharded_state 等）和 warmup 逻辑。
- `entrypoints/`：对外接口层，包含 OpenAI/Anthropic/gRPC/CLI 等多种服务端与命令行入口，统一通过 FastAPI + Uvicorn 启动。
- `v1/`：新一代执行管线（attention/core/engine/executor/kv_offload/spec_decode/structured_output/worker 等），被 engine 层封装后向上暴露。
- `distributed/`：跨设备/进程通信抽象（device_communicators、kv_transfer、weight_transfer、ec_transfer、elastic_ep、eplb）。
- `compilation/`：基于 TorchDynamo + Inductor 的图编译与 CUDA Graph 管理，含 pass 框架与 piecewise backend。
- `multimodal/`、`renderers/`、`tokenizers/`、`parser/`、`tool_parsers/`、`reasoning/`：分别负责多模态输入处理、渲染、分词、结构化输出解析、工具调用解析与推理链解析。
- `platforms/`：CPU/CUDA/ROCm/XPU/TPU/Zen-CPU 等平台抽象，通过 `current_platform` 动态选择。
- 顶层 `__init__.py` 使用 `MODULE_ATTRS` + `__getattr__` 实现延迟导入，避免冷启动开销；`version.py` 独立读取 `_version` 并回退到 dev 版本。
依赖方向自顶向下：entrypoints → engine → v1/model_executor/config/platforms/utils，反向不依赖。
