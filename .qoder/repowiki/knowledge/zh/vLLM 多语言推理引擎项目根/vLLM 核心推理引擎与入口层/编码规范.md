- 配置类统一使用 Pydantic dataclass（`from pydantic import ConfigDict, Field, model_validator`），并通过 `config()` 装饰器与 `replace()` 工具函数提供不可变更新语义。
- 顶层 `__init__.py` 通过 `MODULE_ATTRS` 映射 + `__getattr__` 实现按需延迟导入，避免一次性加载所有子模块。
- CLI 子命令采用 `cmd_init()` 返回命令对象、`subparser_init(subparsers)` 注册子解析器、`validate(args)` 校验参数的三阶段模式。
- 日志统一通过 `init_logger(__name__)` 获取 logger，并使用 `logger.info_once` 避免重复输出。
- 平台相关代码通过 `platforms.current_platform` 动态判断（如 `is_cuda()`, `is_rocm()`, `is_unspecified()`），而非硬编码分支。
- 类型注解普遍使用 `TYPE_CHECKING` 块分离运行时与静态检查依赖，避免循环导入与不必要的 import 开销。
