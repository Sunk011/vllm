- 每个 pre-commit 检查脚本提供 `check_file(filepath)` 函数与 `main()` 入口，通过 `sys.argv[1:]` 接收待检文件列表并以非零退出码报告错误。
- 所有 Python 脚本顶部包含 SPDX 许可证头 (`# SPDX-License-Identifier: Apache-2.0` 与 `# SPDX-FileCopyrightText: ...`)。
- 需要可选依赖的脚本统一使用 `try/except ImportError` 包裹 vLLM/Helion 导入，并在缺失时打印友好提示后 `sys.exit(1)`。
- 构建类脚本通过 `os.environ.get(...)` 读取可配置路径（如 `CUDA_HOME`、`WHEELS_CACHE_HOME`、`NIXL_VERSION`），并提供默认值或交互式回退。
- Helion 相关脚本通过 `vllm.kernels.helion.get_registered_kernels()` 动态发现内核，而非硬编码内核列表，新增内核只需在注册表中声明。
- Shell 脚本遵循 `set -e` 风格并通过 `run_command` 或 `subprocess.check_call` 执行命令，失败时立即终止。
