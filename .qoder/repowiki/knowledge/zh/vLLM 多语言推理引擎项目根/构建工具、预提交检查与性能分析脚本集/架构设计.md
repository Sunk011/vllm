本模块按功能划分为多个独立子目录，彼此无运行时依赖：
- `tools/pre_commit/`：一组独立的 pre-commit 钩子脚本，每个文件实现单一检查（如布尔上下文管理器、禁止导入、SPDX 头、mypy、shellcheck、rust-check、Dockerfile 更新等），通过 `main()` + `sys.exit()` 返回非零退出码驱动 CI。
- `tools/ep_kernels/`：Expert Parallel 内核的安装与系统驱动配置脚本，分两步（Python 库安装无需 root，IBGDA 驱动配置需 root）。
- `tools/profiler/` 与 `tools/profiler/nsys_profile_tools/`：基于 NVIDIA Nsight Systems 的 `.nsys-rep` 解析与可视化，通过 JSON 配置文件映射 kernel 名称到类别。
- `tools/vllm-rocm/`、`tools/vllm-tpu/`：针对 ROCm 和 TPU 平台的 wheel 索引生成与依赖 pinning 脚本。
- `tools/*.py` 与 `tools/*.sh`：顶层构建脚本，包括 Rust 扩展构建 (`build_rust.py` 使用 setuptools-rust)、CMake preset 生成 (`generate_cmake_presets.py`)、DeepGEMM/Protoc/gdrcopy 安装、Ninja 构建时间报告等。
- `scripts/`：Helion 内核的 autotune 与 benchmark 入口，通过 `vllm.kernels.helion` 注册表发现内核，支持 autotune/cuda 两种 baseline。
依赖方向单向：所有脚本均只依赖 vLLM 已安装的 Python 包或外部系统工具（nvcc、nsys、cmake、ninja、apt），不反向依赖项目核心代码。
