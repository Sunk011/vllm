- Expert Parallel 内核：`TORCH_CUDA_ARCH_LIST="9.0" bash tools/ep_kernels/install_python_libraries.sh`，多节点部署后需 `sudo bash tools/ep_kernels/configure_system_drivers.sh` 并 reboot。
- CMake preset：`python tools/generate_cmake_presets.py [--force-overwrite]` 生成 `CMakeUserPresets.json`，然后 `cmake --preset release && cmake --build --preset release --target install`。
- Rust 构建：`python tools/build_rust.py` 调用 setuptools-rust 编译 `vllm._rust_tool_parser` 与 `vllm-rs` 二进制。
- NIXL 源码安装：`python tools/install_nixl_from_source_ubuntu.py`，默认从 GitHub API 获取最新版本，支持 `WHEELS_CACHE_HOME` 缓存 wheel。
- Helion 内核：`python scripts/autotune_helion_kernels.py [--kernels <name>] [--force]` 与 `python scripts/benchmark_helion_kernels.py --kernel <name> [--baseline cuda|autotune]`。
- Pre-commit 检查：各 `tools/pre_commit/*.py` 直接以 `python script.py <files>` 形式运行，返回非零表示失败。
