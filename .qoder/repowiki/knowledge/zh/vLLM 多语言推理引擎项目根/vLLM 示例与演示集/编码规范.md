- 每个示例脚本以 SPDX 许可证头开头，并通过 `if __name__ == "__main__"` 定义入口函数。
- CLI 参数统一通过 `argparse` 或 vLLM 的 `FlexibleArgumentParser` + `EngineArgs.add_cli_args` 构建，默认模型常设为轻量模型（如 Llama-3.2-1B-Instruct、opt-125m）。
- OpenAI 兼容客户端示例固定将 `api_key` 设为 `EMPTY`、`base_url` 指向 `http://localhost:8000/v1`，复用 OpenAI SDK 接口调用 vLLM 服务。
- 自定义扩展点（如 logits processor、pooling 插件）通过继承 vLLM 提供的基类并在 `LLM(..., custom_arg=[...])` 中注册，保持与核心 API 的松耦合。
- Shell 脚本用于封装多步骤部署或示例运行流程，通常命名为 `*.sh` 并与同目录 Python 脚本配套使用。
