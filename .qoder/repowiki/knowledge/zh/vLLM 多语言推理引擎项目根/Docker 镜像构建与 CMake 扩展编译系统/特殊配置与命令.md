- 更新版本：修改 Dockerfile 中的 `ARG` 默认值后运行 `python tools/generate_versions_json.py` 重新生成 `versions.json`。
- 本地构建默认镜像：`cd docker && docker buildx bake`（等价于 `openai` 目标）。
- 构建测试镜像：`docker buildx bake test`。
- 指定 Ubuntu 24.04：`docker buildx bake openai-ubuntu2404`。
- ROCm 构建：使用 `Dockerfile.rocm`，通过 `REMOTE_VLLM`、`VLLM_REPO`、`VLLM_BRANCH` 控制源码来源，`NIC_BACKEND` 选择网卡驱动。
- 启用 sccache：设置 `USE_SSCACHE=1` 并通过 `SCCACHE_ENDPOINT`/`SCCACHE_BUCKET_NAME` 指向 S3 兼容后端。
