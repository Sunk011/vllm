- 所有 crate 共享 `workspace.package`（version/edition/license）与 `workspace.dependencies`，通过 `workspace = true` 引用避免版本漂移。
- 错误类型统一使用 `thiserror` 派生 `Error` 枚举，并通过 `thiserror-ext` 提供 `Result` 别名，错误传播遵循 `anyhow::Context` 包装链。
- 异步运行时基于 tokio multi-thread runtime，通过 `CancellationToken` 实现跨任务取消与优雅关闭，shutdown 流程使用 `tokio::select!` 监听信号、引擎退出与服务终止。
- 配置结构体普遍使用 `serde` 派生序列化，并通过 `validator` derive 宏在 `config.validate()` 中进行字段校验，失败时返回带上下文的 anyhow 错误。
- 测试数据与 fixtures 以 JSON/TXT 文件形式与源码同目录存放，通过 `expect-test` 或 `serial_test` 进行快照/并发测试。
- feature flag 用于可选依赖（如 `native-tls-vendored`、`test-util`、`test-utils`），仅在需要时启用额外功能以保持二进制体积最小化。
